Reste dans le cœur

Wmain (fenêtre, arbre, notebook, menu hamburger), Whost (coquille du dialogue — champs communs Name/Host/Port/User/Password/Group + sélecteur de protocole), Host (modèle générique), GCMBase, persistance gcm.conf, chiffrement, run_dialog_sync, PluginRegistry.

Devient plugin

Chaque XxxTab existant (VncTab, SpiceTab, FreeRdpTab, SerialTab, IpmiSolTab, WebTab) est enveloppé par un adaptateur XxxPlugin implémentant ConnectionPlugin — pas de réécriture, juste une façade. Idem pour SSH : devient SshPlugin, symétrique aux autres.

Service partagé (pas un plugin)

SSHConfigParser/SSHKeyManagerDialog/KeyPickerDialog ne sont utilisés QUE par SshPlugin — ils vivent dans le même paquet/module que lui, mais ne sont pas eux-mêmes enregistrés dans le PluginRegistry (ils n'ont pas de protocole propre).

Refactor nécessaire : Host

Aujourd'hui Host.__init__ connaît en dur chaque champ de chaque protocole (rdp_domain, serial_baud...). Pour une vraie extensibilité, ces champs doivent migrer vers un dict générique options que chaque plugin lit/écrit sous sa propre clé — sinon ajouter un plugin oblige toujours à modifier le cœur.
